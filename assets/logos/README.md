# Logos for the README

The README's logo row is commented out until these files are here and their use is cleared. Both the ESA logo
and the Copernicus logo are trademarks with rules for use by others, so get the files from their owners and the
permission each one needs, then save them here as PNG files about 120 pixels high.

| File | Logo | Where to get it | What its use needs |
|---|---|---|---|
| `esa.png` | European Space Agency | ESA Brand Centre, [brand.esa.int](https://brand.esa.int) | Prior written authorisation from ESA: write to corporatebranding@esa.int ([ESA branding FAQ](https://www.esa.int/About_Us/Branding_and_Partnerships/Frequently_asked_questions)) |
| `copernicus.png` | Copernicus, the EU's Earth observation programme | [copernicus.eu](https://www.copernicus.eu/en/node/97) | The Copernicus trade-mark licence: fill in its registration form; only to refer to Copernicus, without implying EU endorsement |
| `cems.png` | Copernicus Emergency Management Service, which runs EFFIS | [emergency.copernicus.eu](https://emergency.copernicus.eu) | As for the Copernicus logo |
| `effis.png` | European Forest Fire Information System | [forest-fire.emergency.copernicus.eu](https://forest-fire.emergency.copernicus.eu) | Ask the EFFIS team at the Joint Research Centre |

Logos of the authors' institutions (Sapienza, IUSS Pavia, ISPRA) can join the row the same way, with each
institution's agreement.

Once the files are here, remove the `<!--` and `-->` around the logo row near the top of `README.md`. Logos never
replace the attribution text in the README's Licence section, which the Copernicus and EFFIS licences require.
